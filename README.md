# nskt-hub

Web app quản lý học tập NSKT2026 cho BTC: lấy dữ liệu từ dh3g.vn, theo dõi nộp bài, chấm điểm, xếp hạng và báo cáo thống kê.

Đây là dự án mới, tách hẳn khỏi các repo `long-mon-*` cũ.

- Quyết định đã chốt và tiến độ: xem [CLAUDE.md](CLAUDE.md).
- Chạy kiểm tra: `npm install` rồi `npm run check`.
